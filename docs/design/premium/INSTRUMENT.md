# Forecast instrument

Figure tier: one coherent virtual signal console, 70 purposeful parts. It teaches DATA → VALIDATION → MODEL → FORECAST → REVIEW → EXPORT. This is explicitly a conceptual software metaphor, not a physical machine, live processing view, or evidence of model performance.

## Concept and parts plan

A common bed and two continuous guides connect six different mechanisms. Selecting a stage illuminates its assembly and its incoming signal; no part pretends to execute a job.

| Assembly | Parts | Purpose |
| --- | --- | --- |
| Foundation | 13 | Four feet, bed, inset bed surface, two guides, two end stops, identification plate, two signal terminals |
| Data cassette | 9 | Tray, two retaining lips, three record leaves, two locator pins, input socket |
| Validation gate | 10 | Gate foot, two uprights, lintel, inspection pane, four checking bars, output socket |
| Model assembly | 10 | Mount, lower collar, octagonal core, upper collar, selection cap, four selection teeth, input socket |
| Forecast plotter | 10 | Plot bed, chart surface, two guide feet, guide beam, carriage, three path terminals, signal socket |
| Review assembly | 9 | Mount, stem, octagonal gauge body, inset dial, needle, central hub, two retaining pins, signal socket |
| Export cassette | 9 | Receptacle, opening, output leaf, retaining bar, two rollers, two registration pins, signal socket |
| Total | 70 | Paths, chart marks, screws, seams and ruled ticks are surface detail, not inflated part counts |

## Rendering and interaction

- Original server-rendered SVG geometry, built from a small local projection and extruded polygon helpers. No copied kit, runtime library, canvas, shader, or client geometry bundle.
- Native grouped `details`/`summary`: Data starts open. Hover/focus previews the corresponding mechanism; activation expands the full explanation and selects it. Closing the selected disclosure leaves a useful overview. No timers or simulated progress.
- A single short CSS signal sweep occurs when a stage is selected. It denotes reading order only. Reduced motion removes it. Static signal links remain visible.
- Palette inherits Forecast Horizon tokens. Four shaded surfaces establish volume; one mint accent marks the current stage. The six assemblies share one grounded bed rather than six floating cubes.
- All explanations, controls and SVG are in the server response. JavaScript is unnecessary. Browsers without `:has` retain the static complete drawing and native disclosures; browsers without grouped details can show multiple explanations.
- The chart is a schematic branching motif, without statistical axes, numeric results or implied calibrated intervals. The model selector and review gauge carry no invented accuracy values.
